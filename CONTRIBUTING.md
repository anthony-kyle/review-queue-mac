# Contributing

Issues and pull requests are welcome.

1. Fork the repo and branch from `main`.
2. Build and test locally: `make test`, then `make install` to try the app (see the README's build section for requirements).
3. Keep `swift build -c release` free of warnings and add tests for logic changes in `ReviewQueueCore`.
4. Open a pull request against `main`. Every PR needs an approving review from a code owner before it can merge.

By contributing you agree that your contributions are licensed under the MIT License in `LICENSE`.
